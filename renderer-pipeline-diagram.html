Key Architectural Differences

Command Encoding Model

Direct3D 11

  • Immediate context pattern
  • State cached by driver implicitly
  • No explicit command buffer encoding
  • Draw calls execute immediately on context

Metal

  • Command buffer + encoder pattern (deferred)
  • Explicit encoder begin/end
  • Commands recorded, then committed
  • Async completion handlers available

OpenGL

  • Immediate mode state machine
  • Global state context
  • Commands execute when issued
  • Explicit sync with glFinish()

Swapchain Integration

Direct3D 11

IDXGISwapChain
  • RTV created from swapchain backbuffer via GetBuffer(0)
  • Present(sync_interval) for frame presentation
  • Composition scale handled via DXGI

Metal

CAMetalLayer
  • nextDrawable() returns drawable with texture
  • Drawable texture used as render target attachment
  • presentDrawable called on command buffer

OpenGL

Platform-specific
  • GLX/EGL/WGL create drawable surface
  • Default framebuffer (0) is swapchain
  • glSwapBuffers() platform call

Resource Binding

Direct3D 11

  • Vertex: IASetVertexBuffers(slot, ...)
  • Shaders: VSSetShader() / PSSetShader()
  • Uniforms: VSSetConstantBuffers(slot)
  • Textures: PSSetShaderResources(slot)
  • Samplers: PSSetSamplers(slot)

Metal

  • Vertex: setVertexBuffer:offset:atIndex:
  • Shaders: setRenderPipelineState()
  • Uniforms: setFragmentBuffer:offset:atIndex:
  • Textures: setFragmentTexture:atIndex:
  • Samplers: setFragmentSamplerState:atIndex:

OpenGL

  • Vertex: glVertexArrayVertexBuffer() via VAO
  • Shaders: glUseProgram()
  • Uniforms: glBindBufferBase(UNIFORM, slot)
  • Textures: glActiveTexture(unit) + glBindTexture()
  • Samplers: glBindSampler(unit)

Shader Compilation

Direct3D 11

  • HLSL source compiled at pipeline init
  • D3DCompile() produces bytecode blob
  • CreateVertexShader(blob)
  • CreatePixelShader(blob)
  • Entry points: VSMain, PSMain

Metal

  • Shaders compiled to Metal library (.metallib)
  • newLibraryWithSource at runtime or pre-compiled
  • newFunctionWithName() retrieves shader
  • Functions attached to pipeline descriptor
  • Entry points: function names in library

OpenGL

  • GLSL source compiled at program link
  • glCreateShader() + glShaderSource()
  • glCompileShader() per stage
  • glAttachShader() to program
  • glLinkProgram() links stages

Render Pass Flow

Direct3D 11

  • setupPass() binds render target
  • Multiple step() calls with same RTV
  • Draw calls set viewport per step
  • swapchain_pass_bound flag tracks state

Metal

  • MTLRenderPassDescriptor configured up front
  • Encoder created from descriptor
  • All encoded draws share encoder state
  • endEncoding() terminates pass

OpenGL

  • FBO bound per render step
  • Clear on step 0 if clear_color set
  • State implicitly persists across steps
  • Pass boundaries are logical, not API-enforced
